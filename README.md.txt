Actividad BD1 - Unidad 3

Operaciones INSERT, UPDATE y DELETE

Este proyecto contiene el desarrollo de la actividad de aprendizaje de la Unidad 3, en la cual se realizaron operaciones de manipulación de datos utilizando los motores de bases de datos MySQL y PostgreSQL.

Motores utilizados

MySQL

PostgreSQL

Contenido del proyecto

MySQL: instrucciones SQL ejecutadas en este motor.

PostgreSQL: instrucciones SQL ejecutadas en este motor.

INSERT: inserción de registros.

UPDATE: actualización de registros.

DELETE: eliminación de registros.

BACKUP: copia de seguridad de la base de datos.

Propósito

Documentar las instrucciones SQL desarrolladas, sus resultados y los procedimientos realizados durante la actividad.
